AU-05 Bid confirmation · with "skip for this session"

Every bid shows amount, buyer's premium (buyer_premium_bps, 2.5%), estimated total, what is due in 48 h if you win, time left and "bids cannot be withdrawn" before the commitment. The skip toggle is off by default, lives for the session only, is offered only for +1 and +2, and a chip in the bid bar shows it is on. +5 jumps and custom amounts always confirm. Each tap sends one idempotency key; a double tap never makes two bids. Call: place_bid(p_auction_id, p_amount, p_expected_seq, p_idempotency_key) (contract ST-010).

Components

  • BidConfirmSheet (BottomSheet) · MoneySummary variant=bid
  • SkipConfirmToggle (Switch) · ConfirmBidButton
  • BidBar with SkipConfirmChip and QuickBidButton showTotal
  • CustomAmountField (AmountField)

Live behaviour while open

  • Timer keeps counting from server time.
  • If someone outbids while the sheet is open, amounts refresh and the button text changes; it never auto-submits.
  • If the auction extends, the timer jumps and a polite note is announced.

Numbers (synthetic)

  • +1: 8,500,000 → premium 212,500 → total 8,712,500 → due in 48 h 1,907,500
  • +5: 8,700,000 → 217,500 → 8,917,500 → 1,952,500
  • Due = 20% down payment + premium − 5,000 deposit (Q-15 default)
