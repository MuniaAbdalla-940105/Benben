WAL-01 Wallet (Profile / Wallet tab)

Balances come only from the server (wallets.available / locked / pending / forfeited, piasters). Locked shows which auction each lock belongs to and what happens next (deposit timeline, UX 4B). History is the ledger: type, amount, date, related auction. Top-up minimum EGP 5,000 (Q-14 default). Withdrawals arrive in sprint 6 (ST-042).
