PAY-01 Mock checkout (staging only)

Stands in for the Paymob hosted checkout at /dev/mock-checkout/:gateway_order_id. It must look unmistakably like a test tool (striped banner, "TEST" everywhere) so nobody mistakes it for a real payment. QA picks a scenario; the page calls POST /simulate, then redirects back. The redirect never credits money: the app waits for the signed webhook or the inquiry API. The production build must not include this page (NOT_ALLOWED_IN_ENV).
