AU-01 Auctions Home

The app opens here (PRD 3.1). The Live Now hero is the navy stage with lot number, LIVE pill, gold-framed ring and the "Sold for" style results lower down (C, live surfaces only). Everything else is the calm catalogue (B). Modules top to bottom: area chips → Live Now → Ending Soon (< 1 h) → Starting Soon (Remind me) → This week calendar → Just Sold. "For you" is not shown until ST-048. Prices update in place from bid.placed broadcasts.

Components

  • AppTopBar (BrandMark, WalletChip, NotificationsButton) · AreaFilterChips
  • LiveHeroCarousel → LiveHeroCard (stage: LotNumber, LivePill, CountdownRing, LivePrice)
  • EndingSoonRail → AuctionCard variant=ending|final
  • StartingSoonRail → StartingSoonCard + RemindMeButton
  • AuctionCalendarStrip · JustSoldRail → SoldResultRow · BottomNav

Rules

  • Carousel never auto-advances while focused or touched; pause control; reduced motion: no auto-advance (WCAG 2.2.2).
  • Remind me: guest → login sheet; logged in → reminder 1 h and 5 min before, appears under Watching.
  • Empty module: hidden, except Live Now which shows its empty state with the next start time.
  • 4G: hero image ≤ 60 KB AVIF/WebP, rails lazy-load below the fold.

Responsive

  • 768: hero 2-up, rails become 2-column grids.
  • 1280: top navigation replaces the bottom nav; hero + Ending Soon side by side; 3-column grids.
