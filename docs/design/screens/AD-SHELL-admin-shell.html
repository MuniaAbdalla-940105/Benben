AD-SHELL Admin shell, 2FA gate and role-based navigation

Desktop-first at 1280 (shown at 75%). Same tokens as the consumer app, denser: 14 px base for tables, 40 px rows, 36 px controls (still ≥ 24 px targets). TOTP 2FA is required before any module opens. The sidebar shows only the MVP modules the signed-in roles allow (AD-01, 02/03, 05, 07, 09, 11, 14, 15, 16/17); the server enforces the same rule with RLS. Every write asks for a reason and is audited. Arabic and English are both supported; this page shows Arabic, AD-15 shows English.

Components

  • AdminShell · AdminSidebar (NavGroup, NavItem with module code) · AdminTopBar (EnvBadge, UserMenu, LanguageSwitch)
  • TwoFactorGate (TotpSetup with QR, OtpInput) · AccessDeniedPage · ModuleForbidden
  • PageHeader (Breadcrumb, title, actions) · ReasonDialog

Roles shown (Q-69)

  • Example user: منى عادل · Ops Supervisor + Auction Control. Sees AD-01, AD-02/03, AD-05, AD-07.
  • Super Admin sees all MVP modules including AD-14, AD-15.

Safety

  • Environment badge always visible (STAGING amber, PRODUCTION red outline).
  • Destructive actions name the entity in the button ("Cancel LOT 07").
  • Session timeout 30 min idle; re-auth with TOTP.
