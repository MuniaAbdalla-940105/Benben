DS-components · ST-003 · ADR-003

Design system: living component sheet

Every component in every state, light and dark side by side (dark copy generated from the light markup, so both always match). Arabic RTL. Error codes in dotted boxes are annotations for developers (contract codes), not UI text. Tokens: docs/design/tokens.css · Tailwind mapping: docs/design/tailwind-theme.js · Spec: docs/design/design-system.md.

Button · IconButton · TextField · PhoneField · AmountField · Select · OtpInput · Checkbox · RadioCard · Switch · Card · AuctionCard · ListRow · Badge · LivePill · LotNumber · CountdownText · CountdownRing · BidLadder · Tabs · FilterChips · Stepper · BottomSheet · Modal · Toast · InlineAlert · EmptyState · Skeleton · MoneySummary · DepositTimelineCard · BrandMark

1 · Colour roles

Semantic roles switch with the theme; the live stage is the same navy in both themes. Text pairs are AA (values in tokens.css header).

2 · Type scale

IBM Plex Sans Arabic for text, Readex Pro (brand Arabic voice) for display and h1 only, Inter for Latin and every number (tabular figures). Minimum size 12 px. Sizes in rem, so browser font size and 200% zoom are respected.

3 · Button · IconButton

Primary is navy on light, gold on dark and on the stage. One primary per view. Money buttons say the amount ("احجز 5,000 ج.م"). Loading keeps the width and blocks repeat taps (idempotent requests).

4 · TextField · PhoneField · AmountField · Select · OtpInput

Label above, help below, error in text with an icon (never colour only). Inputs accept Latin and Arabic-Indic digits and normalise them. Phone and amount fields are LTR inside RTL.

5 · Checkbox · RadioCard · Switch

6 · Card · AuctionCard · ListRow

AuctionCard always shows the four facts: price, time left (with label), status and the next action. Variants: live, ending soon, final minutes, upcoming (Remind me), sold.

7 · Badge · LivePill · CountdownText · CountdownRing

Timer rule (PRD 3.11): green > 1 h "متبقي", amber < 1 h "ينتهي قريبًا" + clock icon, red < 5 min "الدقائق الأخيرة" + alert icon, bold and boxed. The ring (live stage) keeps a gold frame; the arc carries the state colour and drains counter-clockwise in Arabic. Screen readers hear the timer at 1 h, 5 min, 1 min and on extension only.

8 · BidLadder · Tabs · FilterChips · Stepper

9 · BottomSheet · Modal · Toast · InlineAlert · EmptyState · Skeleton

Sheets trap focus and return it to the trigger; the grip is decorative (close button always present). Toasts use role="status"; outbid and extension use one role="alert" per event.

10 · MoneySummary (receipt) · DepositTimelineCard

Money summaries use tabular numerals, LTR-isolated amounts, a dashed rule before the total, and always name the currency. Timeline states: done (navy dot), now (gold tint), risk (red text, never colour alone), ok.

11 · BrandMark

The logo is not final (ADR-003). Screens reference docs/design/brand/logo/symbol.svg, symbol-on-navy.svg and the horizontal lockups through <img data-brand>; a new mark is a file replacement. Never redraw it in code.
