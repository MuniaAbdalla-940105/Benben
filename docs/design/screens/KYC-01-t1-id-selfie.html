KYC-01 Identity check (T1): National ID + selfie

The only full-screen step of Join to Bid (UX 1A); it returns to AU-04 when kyc.updated arrives. Steps: intro → ID front → ID back → selfie → National ID number and review → checking → result. Target under 3 minutes. Files go to a private bucket; the number is validated on the client and server before any vendor call. Passport is not offered in the MVP (Q-38). Camera screens use the dark stage so the document stands out, in both themes.

Components

  • KycFlow · KycIntro · KycStepper
  • DocumentCapture (camera, frame guide, retake) · SelfieCapture (oval guide)
  • NationalIdField (14 digits, Latin or Arabic-Indic) · KycReview · KycResult
  • MiniAuctionTimer (keeps the auction time visible)

Status mapping (contract ST-005 §3.2)

  • submitted → "جارٍ التحقق…" · approved → success, back to AU-04
  • needs_review → "قيد المراجعة" · failed → reason + retry · rejected → reason + support

Privacy copy

  • Why we need it, who sees it (KYC reviewers only, never the seller), how long we keep it, and a link to the privacy notice (PDPL 151/2020).
