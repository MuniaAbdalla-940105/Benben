AU-06 Auto-bid setup

A money moment: calm sheet, receipt-style summary. The user sets a hidden maximum (≥ current + 1 increment); the system bids the minimum needed to lead, up to the max. Shows the premium and estimated total at the max, so the worst case is clear before saving. One active auto-bid per user per auction; raising is free, lowering must stay above the current price. The data contract for ST-015 is not written yet: error codes below reuse DATA_MODEL §6 codes (INVALID_AMOUNT, BID_TOO_LOW, NOT_PARTICIPANT, AUCTION_PAUSED); the architect may add specific ones.
