AU-03 Live Room (full screen)

The whole room is the navy stage in both themes (ADR-003). Header is A's compact four-facts block: price · time · bidders · my status. Below: small hero image, tabs for Chat / Bids / Ask the seller, and the bid bar. Outbid and extension follow UX 3B: the status strip and timer change state, one vibration, one polite toast; no overlay ever covers the price. No ticker, no slam-in banners (excluded in ADR-003). Chat: aliases only, masking, slow mode 1 msg / 10 s, host messages pinned.

Components

  • LiveRoomPage · FourFactsHeader (LivePrice, CountdownText, BidderCount, MyStatusBar, ExtensionCounter)
  • LiveHeroMedia · Tabs (Chat, Bids, Ask the seller)
  • ChatStream → ChatMessage variant=user|host|system|masked · PinnedHostMessage · ChatComposer (slow-mode countdown)
  • BidLadder · BidBar · ExtensionToast · OutbidStatus · ReconnectBanner

Realtime

  • Events: bid.placed, auction.extended, auction.state_changed, participants.updated.
  • On reconnect: refetch live state, bids since last seq, server time; never replay local state (A6).
  • Ended → route to AU-07 result (ST-028).

Accessibility

  • Chat is a role="log" with aria-live="off" by default (too chatty); a "read new messages" button announces counts.
  • Outbid and extension: one role="alert" each.
  • Light and dark copies are identical by design (stage).
