## Story
As a seller or an auction winner, I want to upload my income/employment or company documents and address proof, so that Benben can approve me for KYC T2.

## Acceptance criteria
- Given a T1 user, when they open T2 verification, then they can upload proof of income or employment (or company documents) and an address proof to a private bucket (PRD 2.2). Decision Q-37: manual upload, no vendor.
- Given a submitted T2 case, when it is saved, then its status is `submitted` and it appears in the KYC Review queue (ST-022) with an SLA.
- Given a T0 user, when they try T2, then they are asked to finish T1 first.
- Given the reviewer requests a re-upload, when the user opens the case, then they see which document and why, and can replace only that file.
- Given approval, when decided, then `kyc_tier = T2` and the user is notified; given rejection, then the reason is shown.
- Given a winner with a 48h obligation (ST-029), when T2 is missing, then the checklist links straight to this flow.
- Given files, when RLS is tested, then only the owner and KYC Reviewers can read them.
