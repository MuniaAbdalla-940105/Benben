## Story
As a Verified Bidder, I want quick bid buttons, a clear confirmation of what I will pay, and live updates when others bid, so that I can bid fast without mistakes.

## Acceptance criteria
- Given a Verified Bidder on AU-02, when the bottom bar renders, then it shows quick buttons +1, +2 and +5 increments and a custom amount input (≥ current + 1 increment).
- Given a bid amount, when the bidder taps it, then the confirmation sheet (AU-05) shows amount, buyer's premium (from `auctions.buyer_premium_pct`, default 2.5%) and estimated total. Assumption (Q-08): no VAT line until Finance confirms.
- Given the "skip confirmation" toggle, when enabled, then it lasts for this session only.
- Given a confirm tap, when the request is sent, then it carries an idempotency key and the button shows loading; a double tap does not send two bids.
- Given another user's bid is broadcast, when received, then current bid, minimum next bid, quick button amounts and bid history update without reload.
- Given the bidder is outbid, when the broadcast arrives, then an outbid alert appears and the device vibrates where the Vibration API is supported (ADR-001).
- Given a rejected bid, when the response arrives, then the message shows the reason (e.g., "Outbid, new minimum is X") and refreshes the amounts.
- Given the bidder is the current leader, when the bar renders, then bid buttons show "You are leading" and are disabled (no self-outbidding, PRD 3.5).
- Given the realtime connection drops, when it reconnects, then the page resyncs state and server time from the server (A6 basic; full Live Room in ST-017).
- Given AR/RTL and digit settings, when amounts render, then they follow ST-002 formatting.
