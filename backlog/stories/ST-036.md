## Story
As a buyer, I want to search fixed-price listings with the filters that matter, so that I quickly find units that fit my budget and needs.

## Acceptance criteria
- Given MK-01, when opened, then it shows a search bar, quick filter chips, a map/list toggle and results of published, non-expired listings only.
- Given MK-02, when opened, then it has the core filters (Decision Q-53): area/compound, type, price min/max (total), bedrooms, size (m²), sale type (primary/resale/تنازل), finishing, delivery (ready / year), with a live result count.
- Given filters, when applied, then results update and the count matches.
- Given map view, when toggled, then listings show as pins; draw-area is not included (Decision Q-53). Assumption (Q-50): Google Maps.
- Given a logged-in user, when they tap "Save search", then the filters are stored; a guest is asked to log in (PRD 2.1).
- Given no results, when shown, then the empty state suggests widening filters.
- Given listings hidden for auction (M4), when searching, then they do not appear.
