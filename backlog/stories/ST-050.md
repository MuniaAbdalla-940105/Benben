## Story
As an Ops agent, I want to turn a seller's "Send to Auction" request into a prefilled auction request, so that Marketplace sellers can move to the auction quickly.

## Acceptance criteria
- Given a Send to Auction request (ST-035), when Ops opens it, then they can create an auction request on behalf of the seller with listing data and media prefilled into AD-05 (PRD M4, Decision Q-53/Q-68).
- Given the seller is not T2, when Ops starts, then the "Request info" path from ST-023 applies.
- Given the auction becomes SCHEDULED or LIVE, when that happens, then the listing is hidden from Marketplace search and detail; the property's single-active-context rule treats "hidden for auction" as inactive. Assumption (Q-57).
- Given the auction ends without a sale and the seller chooses Marketplace, when that happens, then the listing is restored.
- Given the seller, when the request is accepted or rejected, then they are notified.
