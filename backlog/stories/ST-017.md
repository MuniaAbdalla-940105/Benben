## Story
As a Verified Bidder, I want a full-screen live room with the bid ladder, chat and quick bid buttons, so that I can follow and win the final minutes without leaving the screen.

## Acceptance criteria
- Given AU-02, when the user opens the Live Room (AU-03), then it shows the hero image at top, the chat area in the centre (ST-018), the bid ladder, quick bid buttons, the extension toast and the outbid alert.
- Given a guest in the Live Room, when it renders, then everything is read-only and the CTA is "Join to Bid".
- Given the connection drops (A6), when it comes back, then the client resyncs auction state, bids since the last event and server time from the server; nothing is replayed from local state.
- Given the final minute, when the connection is unstable, then a banner recommends setting an auto-bid (A6); there is no compensation for client-side issues.
- Given the auction is PAUSED, when the event arrives, then bid controls are disabled and a "Paused" banner shows; on resume the new `ends_at` is shown.
- Given the auction ends, when `auction.ended` arrives, then controls lock and the user is routed to the result (AU-07, ST-028).
- Given a timer colour rule, when time remains, then green > 1 h, amber < 1 h, red < 5 min.
