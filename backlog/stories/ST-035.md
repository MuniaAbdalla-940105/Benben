## Story
As a lister, I want to track my submissions, fix what reviewers ask, and keep my listings alive or send them to auction, so that I stay in control of my properties.

## Acceptance criteria
- Given AP-03, when opened, then tabs by status (Draft, Submitted, In review, Changes requested, Approved, Rejected, Withdrawn, Expired) show items with SLA countdown and reviewer comments.
- Given Changes requested, when the user edits, then only flagged fields are editable and resubmission keeps its queue place with priority (PRD 8.1.5 A step 5).
- Given an item In review (C1), when the user tries to edit, then edit is blocked and they can withdraw and resubmit.
- Given a published listing, when cosmetic fields change (description, photo order), then they update instantly; when price, main photos, documents or location change, then a new version goes to review while the approved version stays live (PRD 8.1.5).
- Given a listing 30 days old, when the lister has not confirmed "still available", then it expires; confirming renews it for 30 days (PRD 5.3).
- Given MK-07, when opened, then each listing shows status, views, leads, Renew and "Send to Auction".
- Given "Send to Auction", when tapped, then a request goes to Ops with the listing data attached (Decision Q-53); Ops handles it in ST-050.
- Given a listing sold outside Benben (M3), when the lister marks it sold, then it is archived.
- Given the same property rejected 3 times (C2), when the user tries again, then they must contact Ops and the account is flagged.
