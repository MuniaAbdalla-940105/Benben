## Story
As the stakeholder, I want the full auction and marketplace journeys tested automatically and under pilot load, so that the pilot starts without known blocking defects.

## Acceptance criteria
- Given Playwright on staging, when the suite runs, then it covers: guest → OTP → KYC → join → bid → auto-bid → anti-sniping → close → winner completion; default → second chance; reserve not met; cancel (A16); pause/resume (A7); marketplace submit → review → publish → report → hide.
- Given each PRD edge case A1–A16, M3–M4 and C1–C8 that is in the MVP, when the suite runs, then each has at least one automated test or a documented manual test with evidence.
- Given the load test, when re-run at pilot sizing, then 5,000 viewers on one auction and the assumed total pilot connections meet p95 < 300 ms. Assumption (Q-45).
- Given the run, when it finishes, then results are linked in this story and in BACKLOG.md metrics; failures create bug files.
- Given CI, when the regression suite is added, then it runs nightly on staging.
