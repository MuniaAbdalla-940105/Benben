## Story
As a viewer, I want to follow a live chat about the auction, and as a Verified Bidder to write in it, so that I can ask questions and feel the room without exposing my identity.

## Acceptance criteria
- Given any viewer including guests, when they open the Live Room, then they can read the chat (PRD 3.8).
- Given a Verified Bidder of this auction, when they send a message, then it is accepted through a server function and appears with their alias (e.g., "Bidder #7"), never their real name.
- Given a user without an active lock for this auction, when they try to write, then it is refused.
- Given a message containing phone numbers, emails, links or WhatsApp handles, when it is stored, then those parts are masked and `masked = true`.
- Given profanity (Arabic and English list), when sent, then it is filtered.
- Given slow mode, when a bidder sends more than 1 message per 10 s, then extra messages are refused with a wait time.
- Given accepted bids, when they happen, then they appear in the stream as system messages.
- Given the Benben host, when they post, then the message is marked host and can be pinned; hosts are exempt from slow mode. Assumption (Q-31): "Auction Host" admin permission; the seller's agent is out of scope for the MVP.
- Given the "Ask the Seller" thread, when a bidder asks, then the question shows in a separate thread answered by the host. Assumption (Q-31).
- Given chat writes, when a client inserts into `chat_messages` directly, then RLS denies it.
- Given admin mute or ban (ST-025), when applied, then the user can no longer write.
