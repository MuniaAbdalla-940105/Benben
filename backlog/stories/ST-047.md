## Story
As Benben Compliance, I want a flagged or banned user to be stopped everywhere at once, so that one bad actor cannot move from one section to another.

## Acceptance criteria
- Given a KYC flag raised mid-auction (A14), when it is set, then the user's existing bids stay but new bids are refused.
- Given a flagged user leading at close (A14), when the auction ends, then winner status is held pending KYC review for at most 24 h; if not cleared, the win passes to rank 2 through the second-chance flow.
- Given a permanent ban, when an Ops Supervisor approves it, then the user cannot log in to bid, chat, list or report, and their ID and device are blocked (PRD 5.3, 8.1.4, 8.2).
- Given strikes, when stored, then auction-default strikes and listing strikes are separate counters with their own rules, and permanent bans are shared. Assumption (Q-30).
- Given suspensions with an end date, when the date passes, then the user is restored automatically.
- Given User status changes, when they happen, then the user is notified with the reason and the change is audited.
