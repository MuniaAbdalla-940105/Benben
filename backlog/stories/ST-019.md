## Story
As a user, I want to see my Available, Locked and Pending money and top up my wallet, so that I always know what I can bid with.

## Acceptance criteria
- Given the Profile/Wallet tab, when opened, then it shows Available, Locked (with the list of auctions each lock belongs to), Pending, and Forfeited history (PRD 2.3).
- Given a top-up, when the user enters an amount and pays through the gateway (ST-007), then Pending shows the amount until the webhook confirms, and Available updates after confirmation. Assumption (Q-14): minimum top-up EGP 5,000, maximum configurable.
- Given a pending payment (A2), when it is still unconfirmed, then the screen shows "Payment pending" and updates automatically when confirmed or after the 10-minute poll window ends.
- Given a declined top-up (A1), when the result arrives, then the reason is shown and retry is offered.
- Given a duplicate charge (A3), when detected, then history shows the duplicate as refunded.
- Given wallet history, when the user scrolls, then each ledger movement shows type, amount, date and related auction.
- Given an empty wallet, when opened, then the empty state explains deposits and offers top-up.
- Given balances, when shown, then they come from the server; the client never computes balances.
