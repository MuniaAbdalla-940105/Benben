## Story
As a guest, I want to open a live auction and see its countdown, current bid, details and bid history, so that I can decide whether to join and bid.

## Acceptance criteria
- Given staging is seeded, when a guest opens the app, then at least one LIVE auction exists (synthetic New Cairo property) with media, key specs, condition report PDF, payment terms, starting price, current price and `ends_at`.
- Given AU-02, when it loads, then it shows the sticky header (countdown, current bid, bidder count), media gallery, key specs, condition report, payment terms, bid history and the sticky bottom bar with "Join to Bid" for guests.
- Given the countdown, when the client connects, then it syncs with server time and counts down from `ends_at` using the server offset, never the device clock (PRD 3.6). Changing the device clock does not change the countdown.
- Given bid history, when a guest views it, then bidders appear only as aliases (e.g., "Bidder #7") with amount and server time (PRD 2.1, 3.8).
- Given the reserve price, when any non-admin views the auction, then neither the amount nor a reserve status is shown. Assumption (Q-22).
- Given the bidder count, when shown, then it counts participants with an active lock. Assumption (Q-32).
- Given the auctions data, when RLS is tested, then anyone (anon) can read public auction fields and the client can never read `reserve_price`.
- Given loading, empty (auction not found) and error states, when they occur, then the designed state is shown.
- Given the auction ended while open, when `ends_at` passes, then the bar changes to "Auction ended" (final outcome handling is ST-027).
