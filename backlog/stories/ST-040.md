## Story
As a user, I want to get the right alerts on the right channel, and to install Benben on my phone's home screen, so that I never miss an auction moment.

## Acceptance criteria
- Given the app, when opened on a supported browser, then it can be installed as a PWA (manifest, icons, offline shell) (ADR-001).
- Given a logged-in user, when they allow notifications, then a web push subscription is stored; on iOS the app explains that push needs the home-screen install.
- Given an event, when the service sends it, then it uses the channels from PRD 8.3 through adapters: push, SMS, WhatsApp, email. On staging SMS/WhatsApp/email are mocks with a viewable outbox. Assumption (Q-40).
- Given every send, when done, then a `notifications` row stores user, event, channel, payload, sent time and read time.
- Given an in-app notification list, when opened, then the user sees their notifications and can mark them read.
- Given a channel failure, when a send fails, then it retries with backoff and logs the failure.
- Given notifications, when RLS is tested, then users read only their own.
