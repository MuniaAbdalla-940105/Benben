## Story
As a Finance officer, I want to explore the ledger and reconcile it with the gateway every day, so that every piaster is accounted for.

## Acceptance criteria
- Given AD-11, when Finance opens the ledger explorer, then they can search by user, auction, payment or transaction ID and see each transaction's balanced entries.
- Given locks, releases and forfeitures, when Finance opens their tabs, then each lists amount, user, auction, status and time.
- Given the daily reconciliation job, when it runs, then it compares gateway settlement records (mock on staging) with `payments` and the ledger, and highlights mismatches (missing in ledger, missing at gateway, amount differs) (PRD F6).
- Given the wallet cache check, when it runs, then any wallet whose cached balance differs from the ledger is listed.
- Given exports, when Finance exports a date range, then a CSV of ledger entries is produced for accounting.
- Given non-Finance roles, when they open AD-11, then access is denied.
