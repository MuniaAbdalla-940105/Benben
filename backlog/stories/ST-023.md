## Story
As an Ops agent, I want to create an auction request on behalf of a verified seller and check their documents one by one, so that properties can enter the auction pipeline while seller self-service waits for Phase 2.

## Acceptance criteria
- Given AD-05 "Create on behalf", when Ops searches a seller account, then the seller must be KYC T2; if not, Ops can send "Request info" and the status is "Waiting seller" (PRD F1 step 2). Decision Q-68.
- Given a seller, when Ops creates the request, then a signed mandate document must be uploaded, and the seller gets an SMS to confirm within 72 h (PRD 8.1.5 C). If the seller denies, the request is removed (C3).
- Given the property step, when Ops enters data, then it uses the shared property fields (type, area, compound, size, bedrooms, bathrooms, floor, finishing, delivery status and date, payment plan) and media.
- Given the documents step, when Ops uploads them, then the required set is: ownership/contract chain, developer NOC or transfer approval for off-plan units, utilities status, latest installment statement if installments are unpaid (PRD 3.3).
- Given each document, when reviewed, then Ops sets Approve or Reject with a reason per document (PRD F1 step 3).
- Given an inspection, when Ops assigns the partner and visit date, then they upload the partner's report PDF, photos and video. Assumption (Q-71): no partner portal.
- Given the request, when saved, then the auction is DRAFT → PENDING_REVIEW and appears with a 48 h SLA (PRD F1 step 1, 8.1.5 review SLA).
- Given content created by Ops, when it moves to approval, then a different person must approve it (maker-checker, PRD 8.1.5 C, C7).
