## Story
As a user, I want to withdraw my Available balance back to my card or wallet, so that my money is never stuck with Benben.

## Acceptance criteria
- Given Available > 0, when the user requests a withdrawal, then the amount moves from Available to a `withdrawal_pending` state in the ledger and cannot be used for locks.
- Given the payout destination, when the funds came by card or mobile wallet, then the payout goes back to the original source; for Fawry-sourced funds, the user enters a bank account or mobile wallet in their own name. Assumption (Q-14).
- Given the KYC name, when it does not match the payout account name, then Finance sees a mismatch and cannot approve (PRD 2.3 rule 5).
- Given the Finance withdrawals queue (AD-11), when Finance approves a batch, then a second approver is required above the daily threshold (PRD 8.1.4).
- Given approval, when the payout is sent through the gateway adapter (mock on staging), then the user sees "3–5 business days" and the status updates on the payout webhook.
- Given a payout failure, when reported, then the money returns to Available and the user is notified.
- Given a user with a frozen account (A4 chargeback case), when they request a withdrawal, then it is refused.
