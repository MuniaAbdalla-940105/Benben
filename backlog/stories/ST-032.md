## Story
As a Post-Auction agent, I want one desk to track every winner's 48 hours, record calls and handle exceptions, so that as many wins as possible complete.

## Acceptance criteria
- Given AD-07, when opened, then it lists ended auctions with winner, hammer price, 48 h countdown, checklist progress, call log and second-chance status, updated live (PRD F3).
- Given a call, when the agent logs it, then the note and time are stored on the obligation.
- Given contract and payment items, when the agent uploads the signed scan or Finance confirms the transfer, then the checklist updates (ST-029).
- Given a deadline near, when the agent requests one extension of up to 24 h with a reason, then an Ops Supervisor must approve (PRD F3 step 5, 8.1.4); only one extension per obligation.
- Given a misrepresentation dispute (A13), when the winner raises it within the 48 h, then the agent opens a manual dispute case that pauses the timer; a supervisor decision either resumes it, or releases the winner's lock and flags the seller. Assumption (Q-34).
- Given a winner's KYC is flagged (A14), when the auction closes, then winner status is held pending KYC review (max 24 h) and otherwise passes to rank 2 (with ST-047).
- Given all offers fail, when the seller decides, then the agent records relist or move to Marketplace (ST-031).
- Given staffed hours, when auctions are scheduled, then closes fall within staffed hours. Assumption (Q-29).
