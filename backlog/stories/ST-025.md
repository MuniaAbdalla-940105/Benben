## Story
As an Auction Control operator, I want to see all live auctions and act on one in real time, so that I can keep auctions fair and handle incidents fast.

## Acceptance criteria
- Given AD-02, when opened, then it shows a live grid of LIVE/EXTENDED/PAUSED auctions with time left, current bid vs reserve, bidders, bids per minute and a health indicator (green/amber/red), filterable by area and status.
- Given AD-03 for one auction, when opened, then it shows the live bid stream, chat with moderation tools, participants table (alias ↔ real user, visible to admins only) and the event log.
- Given Pause, when an operator pauses (reason required), then the state becomes PAUSED, bids and chat are blocked, and all clients get the event.
- Given Resume, when the operator resumes, then the auction returns to LIVE and `ends_at` is extended by the paused duration + 5 min automatically, and participants are notified (PRD F2 step 6). Assumption (Q-26): same rule for every pause.
- Given Manual extend, when the operator enters minutes and a reason, then `ends_at` moves and `auction.extended` is broadcast. Assumption (Q-25).
- Given Mute/Ban chatter or Freeze bidder, when applied, then the user can no longer write or bid in this auction; existing bids stay.
- Given every action, when done, then it is logged with reason in `audit_logs` and `auction_events` (PRD 8.1.4).
- Given non-Auction-Control roles, when they try these actions, then the server refuses.
