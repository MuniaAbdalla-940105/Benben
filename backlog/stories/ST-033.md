## Story
As an owner or verified broker, I want a simple step-by-step wizard to list my property for sale, so that I can publish it after review without help.

## Acceptance criteria
- Given the "+ Add" button (Profile tab, floating button on Explore, "Sell / List your property" banner), when tapped, then AP-01 shows the submission types with KYC lock badges; in the MVP only "Property for sale" is active and the others show "Coming soon" (auction requests go through Ops, Decision Q-68).
- Given a T0 user, when they choose Property for sale, then they must finish KYC T1 first (PRD 5.3, 8.1.5 A).
- Given the wizard (MK-05 / AP-02), when used, then steps are type → location pin → specs → price & payment → media → documents, with a progress bar and draft autosave.
- Given media, when fewer than 5 photos are uploaded, then the user cannot submit (PRD 5.3).
- Given a new account, when it already has 3 active listings in its first 30 days, then a new submission is refused with a message (PRD 5.3).
- Given the preview step, when shown, then it looks exactly as buyers will see the listing.
- Given submit, when tapped, then status is Submitted, the user sees the expected review time (Marketplace SLA 24 h) and the item appears in My Submissions (ST-035).
- Given a draft older than 30 days, when the reminder has been sent, then the draft is deleted (PRD 8.1.5 A step 6).
- Given a broker, when they list on behalf of an owner, then the broker must have the Broker role (ST-022). Assumption (Q-55).
- Given text fields, when they contain phone numbers or banned words, then the auto-checks flag them (used in ST-034).
