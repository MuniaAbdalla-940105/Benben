## Story
As a Content Reviewer, I want each new listing checked automatically for duplicates, price outliers and contact details, so that I can focus on suspicious listings.

## Acceptance criteria
- Given a submitted listing, when auto-checks run, then results are stored on the submission and shown in AD-16/17 (ST-034).
- Given images, when uploaded, then a perceptual hash is stored per image and compared with all other listings' images; matches above the threshold flag "possible duplicate" with links (PRD 5.3, `media_hashes`). Assumption (Q-54).
- Given address and specs, when similar to another active listing, then it is flagged as a possible duplicate (PRD 5.3).
- Given price per m², when at least the configured number of comparable listings exist for that area and type, then a deviation > 30% from the median flags "price outlier"; with too few comparables the check is skipped and shown as "not enough data". Assumption (Q-54).
- Given description text, when it contains phone numbers, emails, links or banned words, then it is flagged.
- Given stock-photo and watermark-removal detection, when this story ships, then it is not included (later, ai-engineer). Assumption (Q-54).
- Given every check, when it fails to run, then the item is flagged for manual review rather than passed.
