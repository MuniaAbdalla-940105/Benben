## Story
As a buyer, I want to see auctions that match what I already search for, so that I discover auctions instead of only fixed-price listings.

## Acceptance criteria
- Given a logged-in user with saved searches, when AU-01 loads, then the "For you" module lists upcoming and live auctions that match those filters (PRD 3.1 module 6). Buyer Requests matching is Phase 2.
- Given a user with no saved searches, when AU-01 loads, then the module is hidden.
- Given MK-01 and MK-03, when shown, then the "Upcoming auctions like this" rail lists scheduled auctions with the same area and type (PRD 5, 5.6).
- Given no matches, when rendered, then the rail is hidden.
